How it works

The mechanism that makes sub-cent agent-to-agent payments economical: multilateral netting, the same idea a derivatives clearinghouse uses to collapse thousands of trades into a handful of transfers.

01

Agent signs off-chain

EIP-712 payment authorization, x402-style. No gas, no network call, sub-millisecond.

→

02

Backend verifies + ledgers

Signature check, replay check, credit-limit check against AgentRegistry. Instant accept.

→

03

Netting engine collapses

Raw payments → net position per agent → minimum transfer set (greedy heap, or exact DFS for small graphs).

→

04

One settleBatch() tx

Clearinghouse moves internal balances for every net transfer, in a single on-chain transaction.

→

05

Insurance pool backstops

Shortfalls are covered from staked reserves; uncoverable amounts carry into the next cycle, not lost.
